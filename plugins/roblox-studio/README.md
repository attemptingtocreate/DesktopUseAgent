# DesktopUseAgent Roblox Studio Plugin (Phase 2 MVP)

This plugin connects Roblox Studio to the local DesktopUseAgent Windows bridge. The agent hosts a loopback-only HTTP listener; the plugin polls for commands and POSTs results. **Studio plugins cannot host HTTP servers.**

## Requirements

1. DesktopUseAgent Windows agent running on the same machine.
2. Roblox Studio **HttpService** enabled:
   - Home → Game Settings → Security → **Allow HTTP Requests**
3. Opt-in polling from the plugin toolbar button **Enable Agent Bridge**.

## Install

From the repository root:

```powershell
.\scripts\install-roblox-plugin.ps1
```

This script:

1. Builds `DesktopUseAgent.rbxmx` from source Lua via `scripts/build-roblox-plugin.ps1`.
2. Embeds the loopback bridge token inside the plugin model's config ModuleScript.
3. Copies the `.rbxmx` model into `%LOCALAPPDATA%\Roblox\Plugins\DesktopUseAgent.rbxmx`.
4. Applies a restrictive current-user read ACL on the installed artifact when possible.
5. Writes `%LOCALAPPDATA%\DesktopUseAgent\roblox-plugin-config.json` with operator metadata only (**no token**).

Restart Roblox Studio after installation.

## Threat model

- Bridge token is required for every plugin HTTP call and is embedded only in the installed `.rbxmx` artifact.
- Token is generated by the agent and stored at `{dataRoot}/secrets/roblox-bridge-token.dpapi`.
- Operator JSON metadata intentionally excludes the token.
- The install script never prints the token.
- Loopback binding (`127.0.0.1`) limits remote access; local malware or other local processes remain in scope.
- Treat `%LOCALAPPDATA%\Roblox\Plugins\DesktopUseAgent.rbxmx` as a local secret on shared machines.

## Usage

1. Start DesktopUseAgent (agent process must be running to host the bridge).
2. Open Roblox Studio.
3. Click **Enable Agent Bridge** in the DesktopUseAgent toolbar.
4. Use agent/MCP tools:
   - `roblox.plugin_ping`
   - `roblox.get_hierarchy`
   - `roblox.get_selection`
   - `roblox.select`
   - `roblox.set_property`
   - `roblox.open_place` (launches Studio with a place file; separate from plugin bridge)

## Bridge protocol (loopback only)

- Host: `127.0.0.1`
- Default port: `18374` (override with `ROBLOX_BRIDGE_PORT`)
- Auth: query `token=...` or header `X-DesktopUseAgent-Token`
- Endpoints:
  - `GET /v1/health`
  - `POST /v1/register`
  - `POST /v1/heartbeat`
  - `GET /v1/poll?sessionId=...`
  - `POST /v1/result`

Allowed plugin operations only: `get_hierarchy`, `get_selection`, `select`, `set_property`, `ping`. No arbitrary Luau execution.

## Property MVP contract

Primitive properties: `Name`, `Anchored`, `CanCollide`, `CanQuery`, `CanTouch`, `Locked`, `Transparency`, `Reflectance`, `Visible`, `Enabled`, `Value`, `Text`, `BackgroundTransparency`, `BorderSizePixel`, `ZIndex`, `LayoutOrder`, `Rotation`.

Typed properties use tagged JSON/Luau tables:

- Color3: `{ "type": "Color3", "r": 0, "g": 0, "b": 0 }`
- Vector3: `{ "type": "Vector3", "x": 0, "y": 0, "z": 0 }`

Applied to: `Color`, `TextColor3`, `BackgroundColor3`, `Size`, `Position`, `Orientation`.
